# 🐱 桌面宠物使用指南

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `desktop_pet.py` | 主程序源码 |
| `pet_char.png` | 去背景后的角色图片（透明PNG） |
| `requirements.txt` | Python 依赖 |
| `build.bat` | Windows 一键打包脚本 |
| `DesktopPet.spec` | PyInstaller 配置文件 |

---

## 🚀 方法一：直接运行源码（推荐开发调试）

### 1. 安装 Python 3.8+
从 [python.org](https://python.org) 下载安装，**勾选 "Add to PATH"**。

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 运行
```bash
python desktop_pet.py
```

---

## 📦 方法二：打包成 EXE（推荐日常使用）

### 方式 A：一键脚本（最简单）
1. 确保已安装 Python 和 pip
2. 双击运行 `build.bat`
3. 等待完成，EXE 会生成在 `dist/DesktopPet.exe`
4. 把 `dist/DesktopPet.exe` 和 `pet_char.png` 放在同一文件夹，即可双击运行

### 方式 B：手动打包
```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --add-data "pet_char.png;." --name "DesktopPet" desktop_pet.py
```

### 方式 C：使用 .spec 文件
```bash
pyinstaller DesktopPet.spec
```

## 🎮 操作说明

### 左键操作
| 操作 | 效果 |
|------|------|
| **单击角色** | 轮流触发互动：跳跃 → 压扁回弹 → 左右抖动 |
| **双击角色** | 同上 |
| **按住拖动** | 拖动桌宠位置，拖动时随机显示跑姿对话 |
| **滚轮** | 调整桌宠大小（8% ~ 80%） |

### 右键菜单
| 选项 | 功能 |
|------|------|
| 💬 陪我聊聊天 | 随机显示温馨对话 |
| 👋 摸摸头 | 显示撒娇对话 |
| 🍰 喂吃的 | 显示吃东西对话 |
| 🚶 让她走路 / 🛑 停止走路 | 自动在屏幕边缘来回走动 |
| 😴 让她睡觉 / ☀️ 唤醒她 | 进入睡眠模式（呼吸动画+变暗） |
| 🎯 跟随鼠标 / 🚫 停止跟随 | 平滑跟随鼠标移动 |
| 📏 调整大小... | 精确输入缩放百分比 |
| 📌 置顶开关 | 切换窗口是否始终置顶 |
| ❌ 退出程序 | 关闭桌宠 |

### 互动时的对话气泡
- 所有互动都会随机显示对应主题的中文对话
- 气泡自动显示在角色上方，不会遮挡角色
- 如果上方空间不足，自动显示在角色下方

## ⚙️ 特性说明

- ✅ **背景透明**：角色周围完全透明，不遮挡桌面
- ✅ **点击穿透**：只有角色实体区域可点击，透明区域点击穿透到桌面
- ✅ **无边框**：纯角色展示，无窗口边框
- ✅ **始终置顶**：默认置顶，可通过菜单关闭
- ✅ **平滑动画**：跳跃抛物线、压扁回弹、左右抖动、走路起伏、睡觉呼吸
- ✅ **智能边界**：走路时自动在屏幕边缘折返，气泡自动避让边界
- ✅ **拖动跑姿**：拖动时随机触发"冲冲冲"等跑姿对话

## 🛠️ 自定义角色

想把角色换成自己的图片？

1. 准备一张 **去背景的 PNG 图片**（透明背景）
2. 命名为 `pet_char.png`
3. 替换原文件即可

> 建议图片尺寸：宽度 800~1200px，高度比例适中

## ❓ 常见问题

**Q: 双击 EXE 闪退？**
A: 确保 `pet_char.png` 与 EXE 在同一目录下。

**Q: 角色周围有黑边/白边？**
A: 请使用带 Alpha 通道的透明 PNG，可用 Photoshop、remove.bg 等工具去背景。

**Q: 无法拖动？**
A: 必须点在角色实体上（透明区域会穿透到桌面），尝试点击角色身体中央。

**Q: 菜单文字显示为方框？**
A: 系统缺少中文字体，程序已内置 "Microsoft YaHei" 和 "SimHei" 回退。
